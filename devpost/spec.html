🏰 Kingdoms & Dragons — Technical Spec

One web page, two stacked layers: a Phaser 4 world drawn entirely with code, and a Market Royale–style HTML/CSS interface on top. They talk through a small event bus. Vite builds it; GitHub Actions publishes it to GitHub Pages.

💾 Data Model

state = {
  era: 1, wave: 1, waveRepeating: false,
  money, stone, wood, gold,
  castleHp, castleMaxHp,
  inventory: { trapId: count },
  traps: [{ id, trapId, col, row, usesLeft }],
  kills, startedAt, speed: 1 | 2 | 4,
  over, won
}
Where it lives: in memory, in the browser tab, for one run.
Who changes it: only the logic modules, called from GameScene → then state:changed.
Who reads it: the interface, from the state:changed snapshot.
Leave and come back: nothing is saved; reloading starts over.
Time to finish: real clock time from Play to game over.

⚠️ Failure Modes & Fallbacks

Blank page on Pages → base path set; check with npm run preview and the live URL.
Slowdown at 4× → pre-generated textures, cap ~60 live enemies, remove dead sprites immediately.
Interface misaligned with canvas → recompute world→screen positions on resize and castle:moved.
Balance unwinnable/trivial → numbers in one place, dev shortcuts, rule tests.

✂️ Simplified · ✅ Decisions · ❓ Open

✂️ What was simplified
  • Code-drawn art instead of sprites (learner's choice). Swappable later without touching logic.
  • Straight paths instead of winding roads. Winding = new waypoint lists only.
  • Waypoint movement instead of physics.
  • No sound (later enhancement).
  • Dev shortcuts: testing aid, not a player feature.
✅ Learner decisions
  • Phaser 4 + Vite + JavaScript: learn Phaser on the current version.
  • GitHub Pages: free, in the existing repo; repo must be public.
  • Art drawn with code: fastest path to all 5 eras; not hand-painted quality.
  • HTML/CSS interface over the canvas: Market Royale styling; needs an event bus.
  • Learner uncertainty: none identified; learner will read the docs after the build (code tour will point to the key Phaser concepts).
❓ Open issues (tuned during build)
  • Wave length (~20–30 s at 1×), speed levels 1×/2×/4×.
  • Balance numbers: click money, prices, uses 1/3/5, damage, health, speed, drops, upgrade costs.
  • Verify early: Phaser 4.2.1 generateTexture, time scales, input; current GitHub Pages action versions.
